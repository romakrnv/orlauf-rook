# Rook — минимальное приложение для Orlauf Rook (FTMS)

Главный экран: скорость, дистанция, время, шаги, ккал текущей тренировки. Кнопки: Start, Pause, −0.1 / +0.1, Power off. Плюс экраны Stats и Users.

## Сборка
1. Установите Android Studio (Koala или новее), откройте папку `Orlauf`.
2. Дождитесь синхронизации Gradle, подключите телефон (отладка по USB), нажмите Run.
3. Закройте FITSHOW и любые другие приложения, которые держат соединение с дорожкой.
4. Включите дорожку, нажмите «Connect».

Проект не собирался автоматически (в среде разработки не было Android SDK). Проверен только разбор пакетов на ваших логах. Если Gradle или компилятор выдаст ошибку, пришлите текст.

## Как это устроено
- Протокол: стандартный FTMS. Данные: Treadmill Data (0x2ACD, раз в секунду). Команды: Control Point (0x2AD9): `00` запрос управления, `07` старт, `02 <скорость×100, LE>` скорость, `08 01` выключение.
- Дистанция, время, шаги и калории считает приложение, интегрируя скорость: дорожка обнуляет свои счётчики.
- Калории: формула ACSM для ходьбы. Шаги: дистанция / длина шага (по умолчанию рост × 0,415). Вес, рост и длина шага задаются у каждого пользователя («Пользователи» → нажать на пользователя) и хранятся только на телефоне.

## Ограничения дорожки (выяснено по логам)
- Скорость только 1,0–8,0 км/ч. Значения вне диапазона приложение не отправляет (0 км/ч на этой дорожке вызывает разгон).
- «Pause» = 1,0 км/ч, счётчики приложения замирают. Настоящей остановки ленты по Bluetooth нет: `08 02` игнорируется.
- «Power off» (`08 01`) отключает питание целиком, включить обратно можно только кнопкой.
- «Power off» на стоящей ленте (скорость 0) сбивает прошивку. Поэтому Start и Power off — одна кнопка: лента стоит — Start, едет — Power off. После нажатия кнопка заблокирована на 3 секунды (дорожка ведёт отсчёт), чтобы команда не ушла повторно.
- Если связь оборвалась, лента продолжит ехать на текущей скорости: остановить её можно пультом.

## Калибровка шагов
Пройдите 100 шагов, посмотрите дистанцию на экране, делите на 100 и введите результат в поле «Длина шага» у пользователя.

## Пользователи
- На главном экране ряд аватарок (эмодзи на цветном кружке): нажмите, чтобы выбрать, кто тренируется. Если тренировка уже идёт, приложение спросит подтверждение; тренировка сохранится за прежним пользователем.
- «Пользователи»: добавить, изменить, удалить (вместе со статистикой). ★ — избранный, он выбирается при запуске приложения.
- Последнего пользователя удалить нельзя.

## Статистика
- Кнопка «Статистика» в правом верхнем углу. Вкладки: неделя (с понедельника), месяц, год, всё время. Сверху можно выбрать, чью статистику смотреть.
- У каждого пользователя своя история во внутренней памяти приложения: `filesDir/workouts_<id>.csv`, одна строка на тренировку. Удаление приложения стирает историю.
- Новая тренировка начинается после простоя дольше 30 минут или при смене пользователя. Идущая тренировка видна в статистике сразу; законченные короче минуты отбрасываются. Пороги в `Config.kt`.
- Стрик: дни подряд хотя бы с одной тренировкой. Текущий стрик не сбрасывается, пока сегодняшний день не закончился.

## Путешествие
- Внизу «Статистики» — маршруты по всей дистанции пользователя за всё время: «Туда и обратно» → «В Мордор» → дальше сюрприз. Пройденные помечены ✓, будущие скрыты.
- На каждой точке маршрута — цитата. Дошли до точки во время ходьбы — на главном экране появляется карточка с цитатой (не мешает кнопкам, исчезает сама через 20 секунд).
- Маршруты и цитаты — `Journey.kt`. Расстояния — фанатские оценки по картам.

## Резервные копии
- Автоматически: `allowBackup="true"` — Android раз в сутки сохраняет данные приложения в Google-аккаунт (нужно включённое резервное копирование Google на телефоне) и восстанавливает при переустановке.
- Вручную: «Users» → Export / Import. Один JSON-файл со всеми пользователями и статистикой; можно сохранить сразу в Google Диск.
- Восстановление из автобэкапа работает, только если приложение подписано тем же ключом. Отладочный ключ лежит в `~/.android/debug.keystore` на Маке — его стоит сохранить.
